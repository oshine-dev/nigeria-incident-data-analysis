# Nigeria Incident Data Analysis

## Project Overview
This project explores incident data in Nigeria to identify trends in reported incidents, deaths, and the distribution of incidents across states.

## Objectives
- Analyze incident trends by year and month.
- Identify states with the highest number of incidents.
- Identify states with the highest total reported deaths.
- Examine incidents with the highest reported death tolls.
- Present key findings using charts and a Streamlit dashboard.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Streamlit
- GitHub

## Key Findings
- 2023 and 2024 recorded the highest number of incidents in the analyzed dataset, with 2,613 incidents each.
- 2024 recorded the highest total reported deaths, at 12,238.
- The incident titled "Herdsmen Attack, Benue" recorded the highest reported death toll in the dataset, with 244 deaths.
- Incident titles frequently contained terms relating to crashes, vehicles, and security events.

## Project Files
- `cleaned incidents.csv` — incident dataset used by the dashboard.
- `app2.py` — Streamlit dashboard application.
- `requirements.txt` — Python dependencies.
- `README.md` — project documentation.
